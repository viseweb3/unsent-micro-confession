One micro-confession, in exactly two parts: a To: line naming who it was meant for, and the unsent message itself — one line, written exactly as it was typed, with no explanation after it. It stayed in drafts for twelve years because sending it would mean giving back the only hug it ever bought.

## Run it

```sh
bun run main.ts
```

(`node main.ts` works too.)
